# Decisions

Every choice `SPEC.md` left open, one line each: `date · topic · choice · why`.

- 2026-10-29 · npm scope · keep `@blacklight`, `create-blacklight`, `blacklight-vscode` · none of these names has a published package (registry 404, scope search empty). npmjs.com refuses unauthenticated checks of org ownership, so the owner must create the `blacklight` npm org before the first publish; if it is taken, switch to `@blacklight-engine` and record it here.
- 2026-10-29 · TypeScript version · 6.0.3, not 7.0 · typescript-eslint 8.72 (required for linting) supports TypeScript < 6.1; move to 7 when typescript-eslint supports it.
- 2026-10-29 · package manager · pnpm 12.16.1, installed by each developer (https://pnpm.io/installation) and pinned in `packageManager` · current release at project start; contributors install pnpm and the dependencies before anything else, no wrapper. Install scripts are opt-in (`allowBuilds` in `pnpm-workspace.yaml`): only esbuild for now.
- 2026-10-29 · Vite entry · the CLI writes `index.html` and `main.ts` into `<game>/.blacklight/` (git-ignored) and roots Vite there · games have no boilerplate HTML or bootstrap file, and the output lands at `dist/index.html` without renaming.
- 2026-10-29 · build base URL · `./` (relative) · the same web build must load from a web path, Electron's custom protocol and Capacitor's WebView.
- 2026-10-29 · scene discovery · `import.meta.glob('../scenes/*/*.scene.{ts,js}')`, file name must equal folder name · one chunk per scene (RT-03) with no registration code; the name check catches typos at startup.
- 2026-10-29 · config validation · hand-written validator in core, no schema library · keeps `@blacklight/core` small (NF-04); errors list every field with its fix.
- 2026-10-29 · display objects before RT-05 · core re-exports PixiJS `Container`, `Graphics`, `Sprite`, `Text` · templates import only from `@blacklight/core`; the engine's own classes replace them in phase 1 under the same names.
- 2026-10-29 · fixed-step epsilon · 1e-6 ms tolerance in the accumulator · float drift otherwise drops a step (144 frames of 1000/144 ms made 59 steps instead of 60).
- 2026-10-29 · docs fonts · Google Sans Flex (SIL OFL 1.1) bundled from blacklight-website · OFL is not in SPEC §9's list but allows bundling and redistribution with any software; it is used only by the docs site, never shipped in games.
- 2026-10-29 · docs branding · BlackLight black theme and hanging-bulb logo from blacklight-website · owner asked for the docs to follow blacklight-sso / blacklight-website.
- 2026-10-29 · engine linking for local tests · `create-blacklight --link <checkout>` writes `link:` dependencies; the dev server allows the linked workspace in `server.fs.allow` · lets the phase gates scaffold and run a real project against unpublished packages.
- 2026-10-29 · logical vs display position · `GameObject.x/y` hold the logic position; the display (`position`) is interpolated between steps · rendering at 144 Hz stays smooth while logic runs at 60 Hz; `teleport()` skips the interpolation.
- 2026-10-29 · display objects · engine classes extend Pixi `Container` and hold the Pixi object (`view`, `draw`) instead of extending Pixi `Sprite`/`Text` · one base class (`GameObject`) for every object; Pixi classes cannot share a base otherwise.
- 2026-10-29 · object discovery · `objects/<name>/<name>.object.ts` and `scenes/<s>/objects/<name>/…` are found by glob and named in PascalCase after the folder · names survive minification; `spawn('Name')` and `is('Name')` work without registration code.
- 2026-10-29 · asset preloading · a scene preloads its `static assets`, everything in `scenes/<name>/assets/`, and the files of every object class it can spawn; fonts in `assets/` load at start · sprites and sounds can then be used synchronously; global `assets/` stays on demand so big games do not load everything at boot.
- 2026-10-29 · asset manifest · the CLI scans the project and serves a virtual module (`virtual:blacklight/assets`) mapping project paths to URLs · Pixi would otherwise need hand-written bundles; file renames are picked up by the watcher.
- 2026-10-29 · atlases · release builds pack PNGs up to 1024 px into 4096² shelf-packed pages with 2 px extruded padding (pngjs); dev serves the files directly · RT-08; JPEG/WebP stay separate (rarely small sprites).
- 2026-10-29 · texture resolution · textures load with resolution 1 · Pixi reads `@16x16` in grid sheet names as an `@16x` HiDPI suffix.
- 2026-10-29 · Motion · easings and spring math come from Motion; the tween scheduler is the engine's, on the fixed step · Motion's own frame loop runs on requestAnimationFrame and would not pause with the game or replay deterministically (RT-14).
- 2026-10-29 · gamepad database · SDL_GameControllerDB is bundled in core as a lazy chunk (612 KB raw), refreshed with `pnpm --filter @blacklight/core update:gamepads`; only loaded when a pad without the standard mapping connects · offline play, no download at runtime.
- 2026-10-29 · player 1 and gamepads · player 1 reads every device until a second player joins; then it keeps the keyboard and the first pad it used · solo games need no setup, join screens still work.
- 2026-10-29 · typed names · the CLI writes `.blacklight/types.d.ts` (Register: scenes, objects, actions, animations, assets) on dev, build and `blacklight types`; scenes, objects and actions are strict unions, animation and asset names are suggestions · CLAUDE.md asks for typed names; animations and assets also accept computed strings.
- 2026-10-29 · `.anim.json` typing · `static animations` accepts the JSON import type (`AnimationFileInput`), hitboxes are checked by the JSON Schema rather than TypeScript · JSON imports do not have literal types, so `"type": "box"` would not narrow.
- 2026-10-29 · physics package · `@blacklight/physics` awaits Rapier's WebAssembly at import (top-level await) and steps one world per scene on the fixed step · rigid bodies can be created synchronously in `create()`.
- 2026-10-29 · snapshots · `scene.snapshot()` saves core fields, the fields a subclass declares (or `static serialize`), references as ids, behavior and animation state, random state and cameras as JSON; timers are kept in memory only · closures cannot be serialized; rollback runs in memory, saves do not need timers.
- 2026-10-29 · test fixture · `e2e/fixtures/runtime` is a small game in the workspace, assets generated by `e2e/fixtures/generate-runtime-assets.mjs` · gates need a real project; generated art avoids licensing questions.
- 2026-10-29 · screenshot references · one reference per screenshot for all OS (`snapshotPathTemplate` without platform), 1 % pixel tolerance, gate scenes avoid text · font rendering differs between OS; shapes and pixel art do not.
- 2026-10-29 · collision masks · one-sided: `a.onCollide(b)` only when `b`'s layer is in `a`'s mask; solids block a mover only when the solid's layer is in the mover's mask · matches Godot/Phaser, so a pickup with an empty mask can stay silent while the player hears it.
- 2026-10-29 · physics stepping · packages hook into `scene.afterObjects` (after objects, before collision detection); Rapier bodies turn hitbox events off (`collision.events = false`) · one world step per scene step whatever the object order, and contacts are reported once.
- 2026-10-29 · restoring re-created objects · `restore()` calls `onRestore()` instead of `create()` · `create()` may spawn children or play sounds that the snapshot already contains.
- 2026-10-29 · camera shake randomness · cameras draw shake from a cosmetic generator, not `scene.random` · visual effects must not change the gameplay sequence (replays, rollback).
