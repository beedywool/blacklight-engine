# 2D with 3D

A Blacklight Engine template: glTF models inside a 2D scene. Robots walk between a 2D background
and a 2D foreground, sorted by depth with 2D bushes; a portrait in the corner is a model rendered
to a texture with a filter and a mask; the pause menu (Escape, Start) shows the hero turning in a
Vue screen.

```sh
pnpm install
pnpm dev
```

| Where                    | What                                                                                    |
| ------------------------ | --------------------------------------------------------------------------------------- |
| `scenes/title`           | 2D title: no 3D code loads until the arena starts                                       |
| `scenes/arena`           | Layers `back`, `actors`, `front`; `static layers3d` gives `actors` a perspective camera |
| `scenes/arena/objects/*` | `Model3D` objects: the hero (arrows, WASD, stick; X waves), a Draco guard, a KTX2 crate |
| `scenes/bench`           | Benchmark: two animated 10 000-triangle models; open `/#bench` to run it                |
| `ui/PauseMenu.vue`       | The menu, with `<ModelView>` from `@blacklight/three/ui`                                |
| `models/`                | `hero.glb`, `hero-draco.glb`, `crate.glb` (CC0, generated by code)                      |

The models were generated by `packages/three/scripts/generate-models.mjs` in the engine repository;
replace them with your own `.glb` files (Blender: File › Export › glTF 2.0).
