# Recipes

Short answers to "how do I…" with the code that does it. Each recipe uses the public API only and links to the guide pages that explain the parts. Recipes with a live preview run the real engine: edit the code and the preview restarts.

| Recipe                                    | What it shows                                                                    |
| ----------------------------------------- | -------------------------------------------------------------------------------- |
| [Pause menu](./pause-menu)                | A pushed screen over the game, input blocked below, a setting changed live.      |
| [Shooting](./shooting)                    | Spawning bullets with a fire rate, collision layers, cleaning up off screen.     |
| [Hit feedback](./hit-feedback)            | Screen shake, blinking invulnerability, damage numbers and knockback on contact. |
| [Health bars over enemies](./health-bars) | DOM gauges that follow game objects, clicks on objects.                          |
| [Touch controls](./touch-controls)        | An on-screen joystick that drives the same actions as the keyboard.              |
| [Local multiplayer](./local-multiplayer)  | Gamepads joining as players 2 to 8, or two players on one keyboard.              |
| [Split screen](./split-screen)            | One camera per player on halves of the screen.                                   |
| [Save and continue](./save-and-continue)  | A "Continue" entry that appears once a save exists, and autosave.                |
| [Custom loading screen](./loading-screen) | Drawing your own progress while scene assets load.                               |

The [playground](/playground) runs a whole project the same way; the [getting started guide](../guide/getting-started) builds one from scratch.
