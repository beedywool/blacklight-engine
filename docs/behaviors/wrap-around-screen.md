# wrapAroundScreen

Leaving one edge of the scene brings the object back from the opposite edge, as in Asteroids.

| Option   | Default | Meaning                                          |
| -------- | ------- | ------------------------------------------------ |
| `margin` | `0`     | Distance outside the bounds before wrapping, px. |
